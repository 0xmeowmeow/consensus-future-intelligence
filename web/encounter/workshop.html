What stays when a token arrives?

          

            A decoder can process its prefix once, keep each layer’s keys and
            values, and then process one new position per step. The new query
            still attends across the accumulated keys. The cache is working
            state for this sequence, not a weight update or a memory of other
            sessions.

Where do the pieces come from?

          

            The measured side uses SmolLM2’s unchanged tokenizer. The editable
            side implements byte-pair merging from scratch: start with 256 UTF-8
            bytes, merge adjacent pairs, and watch the pieces change. It has no
            normalization, word splitter or special tokens.
          

        

        

          
          

            
          

          

            Edit the merge rules yourself
            

              Each pair names two byte IDs (0–255) or IDs created by earlier
              rules (256 + rule rank). Rules apply in the listed order. Changing
              order can change both segmentation and ID meaning.
            

            
            

              
            

          

        

        

      

      

        

          Sources, scope and the next level down
          

            All measured tensors come from the pinned local checkpoint using
            Transformers’ eager Llama implementation in float32 on CPU. Receipts
            identify weights, tokenizer artifacts and runtime. The operation
            diagram names the actual selected block; it is not to scale.
